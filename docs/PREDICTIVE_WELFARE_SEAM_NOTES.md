# First integration invariants

This file records deliberately narrow invariants for the first real 2010->2024 target-year sample poverty smoke.

- sampler release identity remains authoritative for person/household membership and geography IDs;
- `design_inverse_probability_weight` is audit/design metadata, not an approved poverty analysis weight;
- first research estimation uses explicit unit household weights;
- semantic-plane P02/P03 are used only through their already-approved mappings;
- predictive welfare remains a household-level marginal distribution, not a precomputed poverty probability;
- household-specific CBA/CBT lines remain owned by Poverty;
- predictive FGT0/1/2 are integrated from the welfare distribution at those household-specific lines;
- aggregate standard errors/confidence intervals remain `not_supplied`;
- monetary references must match exactly before measurement;
- collective/private dwelling refinement is deferred for this first smoke;
- Q8 transport caveats remain attached to any Census result.
